# For the assistant pushing this to GitHub

- This folder (`github\LGEngine`) IS the repository root. Push everything in it, and nothing from outside it.
- Never add binaries (exe, dll, pdb), pictures, logs or ini files; `.gitignore` already keeps them out.
- The parent project (`ToastMover`) holds the app, local tools and personal settings: do not push it.
- Before pushing, ask the owner: the repository name, public or private, and (if public) the license.
- The folder is regenerated by `ToastMover\tools\export-github.ps1`; if the engine changed, run that first.
